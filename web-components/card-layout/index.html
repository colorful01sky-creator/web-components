イベント（四季の楽しみ）

四季折々の祭典や、街を彩るアートイベントを企画・運営しています。

春｜季節の花まつり

季節の花をみつけて春を自然を体感しよう。

夏｜盆踊り

老若男女、昔ながらの伝統から今の時代の曲まで楽しく踊ろう！

秋｜街角アートフェス

街全体をキャンバスに！多世代が参加できるスタンプラリー形式のアートフェスで、地元の魅力を再発見しましょう。

冬｜マラソン大会

大人から子どもまで参加できる、街を駆け抜けるコース。
